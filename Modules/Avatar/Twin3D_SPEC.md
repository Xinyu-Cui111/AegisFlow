Twin3D 视觉与交互规范草案

目标：提升视觉真实感与交互流畅度，优先低性能开销下的拟真动画与触控反馈。

视觉要点
- 光照：启用环境光纹理（HDRI）或增强环境光强度（默认 1.0→1.2-1.6）。
- 材质：采用 PBR（physicallyBased）材质，使用高光/粗糙度贴图（必要时统一使用色块+轻微高光）。
- 阴影与AO：使用柔和投影阴影，依场景简化 AO 效果以提升立体感。
- 抗锯齿：SCNView 使用 multisampling4X，帧率优先 60fps。

交互要点
- Idle 动画：呼吸（scale 0.98-1.03，时长 ~2.4s 循环）、微摆（y 角 ±0.06，时长 4s 循环）、眨眼（3-5s 随机间隔）。
- 触摸反馈：单击→弹跳（y +0.35）、短暂眼睛/头部表情；长按→轻量摇晃。
- 拖拽：水平拖拽映射为模型 yaw 旋转，实时响应；结束时施加基于速度的惯性旋转并缓和回正。
- 相机反馈：拖拽时相机进行平滑副旋转/视野微缩，触发动作（生成/跳跃）时相机做短暂的 fieldOfView 缩放（0.1s 缩，0.25s 回）。
- 粒子/互动：点击产生小粒子（心/星），数量与寿命控制在低负载下视觉明显。

动画参数建议（可调）
- 呼吸：scale to 1.03 / 0.98，duration 1.2 each，timing = easeInOut
- 眨眼：close duration 0.08, open 0.12, interval 3±2s
- 拖拽角度映射系数：pixels→radians = 0.0009（乘子可微调）
- 惯性系数：velocity * 0.00008 → rotation radians，duration clamp 0.18..1.0
- 相机平滑时长：0.25~0.45s
- 相机 fieldOfView 动画：缩放到 50（默认 60）持续 0.12s，恢复 0.25s

性能与可配置
- 使用 LOD（简化网格）或基于设备性能自动降低粒子/贴图分辨率。
- 延迟加载外部模型与贴图，默认使用本地占位低多边形模型以保证首屏流畅。
- 提供 `settings.performanceMode` 切换，快速降低渲染质量。

增量实现计划（短期 2 天）
1. 基础：已实现呼吸/眨眼/点击弹跳；加入拖拽映射与惯性（已开始）。
2. 相机：加入平滑相机转向与行为（接下来补丁）。
3. 表情与材质：短期调整 PBR 表现与头部发光/高光效果。
4. 优化：添加性能模式与粒子开关。

验收标准
- 拖拽时模型转动平滑、有自然惯性且不抖动。
- 单击反馈有弹跳与短暂相机视角响应。
- 整体保持 50-60 fps 低端机（性能模式可降级）。
